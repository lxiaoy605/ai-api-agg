## 发现问题

### 🟡 严重

**1. Dashboard 新用户引导缺失**
- **现象：** 新注册用户（无 API Key）Dashboard 不显示空状态引导横幅，而是显示 mock 统计数据（Active Channels: 5, Today's Requests: 12,847 等）。
- **影响：** 新用户不知道下一步该做什么（创建 API Key）。"Create your first API key" 按钮被淹没在 mock 数据中。
- **位置：** `/dashboard`
- **建议：** 当用户 API Key 列表为空时，显示引导横幅 "Create your first API key to get started" 及相应按钮。

**2. 语言切换导致页面崩溃**
- **现象：** 点击侧边栏 RU 按钮后，页面组件丢失（只显示 TopNav + "404 This page could not be found."），回到 `/` 后恢复为英文。
- **影响：** 语言切换功能完全不可用。用户在非 EN 语言环境无法使用产品。
- **位置：** Sidebar locale switcher（所有页面）
- **建议：** 修复 next-intl locale 路由切换逻辑。可能的原因是 locale 切换后没有正确匹配路由/组件树。

### 🔵 建议

**3. Delete 对话框按钮使用 unlocalized key**
- **现象：** Delete 确认对话框的确认按钮文本显示 `apiKeys.delete`（i18n key 未被正确解析）。
- **位置：** `/api-keys` → Delete 确认对话框
- **建议：** 确认 `apiKeys.delete` 在 `messages/en.json` 中存在对应值，或修复 key 引用方式。
