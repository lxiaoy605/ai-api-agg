## 🔴 阻塞：品牌/定位不一致

### B1. 品牌名称完全错误

| 位置 | 当前状态 | 设计要求 |
|------|---------|---------|
| `layout.tsx` metadata | `"API Hub — Unified AI API Platform"` | `"AiflowHub — Chinese AI Models. One Global API."` |
| `layout.tsx` description | `"DeepSeek, GPT-4o, Claude, GLM and more…"` | 应强调"中国模型出海"定位，GPT-4o/Claude 非中国模型 |
| `page.tsx` footer | `"API Hub"` | `"AiflowHub"` |
| `sidebar.tsx` brand text | `t("brand")` (翻译为 "API Hub") | 必须统一为 "aiflowhub" 全小写 |
| `page.tsx` hero | 无品牌标语 | 必须出现 "Chinese AI Models. One Global API." |

**修复方案**: 全局替换品牌名称 "API Hub" → "aiflowhub"（全小写），更新所有 meta 标签、footer、sidebar logo 文本。

### B2. Logo 完全缺失

| 位置 | 当前状态 | 设计要求 |
|------|---------|---------|
| `TopNav.tsx` | ⚡ emoji + 蓝色方块 | 五角/六角网络节点图标 + "aiflowhub" 字标 |
| `Sidebar.tsx` | `<Zap>` icon（闪电） | 同上 |
| `page.tsx` | 无独立 Logo 展示 | 首页应展示品牌图形 |

**修复方案**: 使用 DESIGN.md §1.2 定义：创建 SVG 组件 `BrandLogo`，五角/六角节点 + 中心发光源 + 辐射线。独立图形 24×24px，字标 120px。

### B3. Hero 标语与品牌定位脱节

| 位置 | 当前状态 | 设计要求 |
|------|---------|---------|
| `page.tsx` title | i18n key `home.title` | 必须传达"中国模型出海"叙事 |
| `page.tsx` subtitle | `home.subtitle` | 应强调"Chinese AI Models"而非通用 API 聚合 |
| `page.tsx` models section | DeepSeek / Zhipu AI / MiMo (仅3个) | DESIGN.md 提及 DeepSeek/GLM/Qwen/MiniMax/Moonshot 五大模型 |
| `page.tsx` CTA | "Unified API Platform" 叙事 | 应转为"中国模型统一入口"叙事 |

**修复方案**: 重写 landing page 文案，以 "Chinese AI Models. One Global API." 为核心 tagline。模型区展示 5 个模型而非 3 个，增加 GLM、Qwen、MiniMax、Moonshot。

## 🟡 严重：组件/配色偏差

### S1. 全局配色使用 Tailwind 原生色值，未使用品牌 Token

这是最严重的技术偏差。整个代码库硬编码 Tailwind `blue-500` / `slate-*`，DESIGN.md 定义的 `brand.600` (`#3B2FCE`) 从未出现。

| 用途 | 当前值 | 设计 Token | Δ 说明 |
|------|--------|-----------|--------|
| **主按钮背景** | `#3b82f6` (blue-500) | `brand.600` `#3B2FCE` | 蓝色→深紫蓝，色相偏移 48° |
| **主按钮 hover** | `bg-blue-400` | `brand.700` `#2D22A3` | 亮蓝→深紫 |
| **图标/强调色** | `#3b82f6` (blue-500) | `brand.600` `#3B2FCE` | 全站图标色错误 |
| **选中态背景** | `bg-blue-500/10` | `rgba(59,47,206,0.15)` | opacity 相近但基色错误 |
| **选中态文字** | `text-blue-400` | `brand.300` `#C4B5FD` | 蓝色→淡紫 |
| **选中态边框** | `border-blue-500/20` | `1px rgba(123,97,255,0.25)` | 蓝色→品牌紫 |
| **渐变效果** | 无 | `135deg #3B2FCE→#7B61FF` | 完全缺失品牌渐变 |

**修复方案**: 
1. 在 `globals.css` 用 Tailwind v4 `@theme` 块定义 `--color-brand-*` 和 `--color-neutral-*`
2. 全站 `#3b82f6` → `brand-600`，`bg-blue-*` → `bg-brand-*`
3. 添加品牌渐变 utility class `bg-gradient-brand`

### S2. 中性色偏差

| 用途 | 当前值 | 设计 Token | Δ |
|------|--------|-----------|------|
| 页面背景 | `#0a0a10` | `neutral.950` `#0A0A10` | ✅ 值一致，但应通过 CSS 变量引用 |
| 卡片背景 | `#141620` | `surface-elevated` `#161625` | Δ 2 (R-2, G+2, B-5) |
| 卡片 hover | `#1a1d2e` | 无对应 token（不在此系统） | ❌ 不应存在 |
| 边框色 | `#1e2030` | `neutral.600` `#2E2E3F` | Δ 严重：太暗，对比度不足 |
| body 文字 | `#e2e8f0` | `neutral.50` `#F8F8FC` | 色相偏移：slate→warm-gray |
| muted 文字 | `#94a3b8` | `neutral.300` `#A0A0B0` | 紫调不足 |
| secondary 文字 | `#64748b` | `neutral.400` `#707088` | 紫调不足 |

**修复方案**: 替换所有中性色为 DESIGN.md 定义的 `neutral.*` token，通过 CSS 变量引用。

### S3. 侧栏背景色偏差

| 位置 | 当前值 | 设计 Token |
|------|--------|-----------|
| Sidebar bg | `#050510` | 应等于页面背景 `neutral.950` `#0A0A10` 或略深 |

`#050510` 不在设计系统中。侧栏应与页面背景一致或使用 `neutral.900` (`#0E0E1A`)。

### S4. 按钮组件不符合设计规范

| 属性 | 设计规范 (primary md) | 当前实现 | 偏差 |
|------|---------------------|---------|------|
| 背景 | `brand.600` `#3B2FCE` | `#3b82f6` | 🔴 色值错误 |

| 字号 | 14px | 14px (text-sm) | ✅ |
| 圆角 | 8px (rounded-lg) | 8px (rounded-lg) | ✅ |
| fontWeight | 600 (semibold) | 500 (font-medium) | ⚠️ 偏细 |
| Hover | `brand.700` | `bg-blue-400` | 🔴 色值错误 |
| Focus ring | 2px brand.500 offset 2px | 无 | ❌ 缺失 |

## 🔵 建议：细节优化

### D1. 字体栈不完整

| 需求 | DESIGN.md | 当前实现 | 状态 |
|------|----------|---------|------|
| Sans-serif | `Inter Variable, Inter, SF Pro Display, system-ui, sans-serif` | `"Inter", ui-sans-serif, system-ui, -apple-system, sans-serif` | ⚠️ 缺 Variable/Display/CN |
| Mono | `JetBrains Mono, Fira Code, Cascadia Code, SF Mono, ui-monospace, monospace` | 无定义 | ❌ 完全缺失 |
| CN fallback | `PingFang SC, Microsoft YaHei, Noto Sans SC` | 无 | ❌ 完全缺失 |
| 加载方式 | `@font-face` Inter Variable + woff2 | 无 | ❌ 依赖系统字体 |

**修复方案**: 
1. 添加 Inter Variable `@font-face` 声明（woff2 自托管或 next/font）
2. 添加 JetBrains Mono for code
3. 添加中文字体 fallback stack
4. 字体栈末尾追加 `PingFang SC, Microsoft YaHei, Noto Sans SC`

### D2. 排版标度使用不规范

| 位置 | 当前实现 | 设计要求 | 偏差 |
|------|---------|---------|------|
| Hero 标题 | `text-5xl sm:text-6xl lg:text-7xl` | max `text-5xl` (56px) | ⚠️ 超出设计上限 |
| Hero 副标题 | `text-base sm:text-lg` | `text-lg` (18px, 28px leading) | ⚠️ 未指定 leading |
| Section 标题 | `text-sm font-semibold tracking-wide uppercase` | `text-xl` (20px, weight 600) | ⚠️ 层级过低 |
| 卡片标题 | `text-sm font-semibold` | `text-lg` (18px, weight 500) | ⚠️ 尺寸偏小 |
| 特性描述 | `text-sm leading-relaxed` | `text-sm` (14px, 20px leading, not relaxed) | ⚠️ leading 不一致 |

**修复方案**: 严格遵循 DESIGN §2.1 Type Scale，Hero 限制到 `text-5xl` (56px) 上限。

### D3. 缺少 letter-spacing 规范

| 设计规范 | 当前实现 |
|---------|---------|
| Headings xl+: `-0.02em` | `tracking-tight` (~0.025em) |
| Body/UI: `-0.01em` | 未设置 |
| All-caps badges: `+0.05em` | `tracking-wide` (~0.025em) |

### D4. 间距偏离 4px 网格

| 位置 | 当前值 | 问题 |
|------|--------|------|
| TopNav padding | `px-4` (16px) | ✅ ok |
| 按钮 padding-y | `py-2.5` (10px) | ❌ 不是 4 的倍数 |
| 按钮 padding-y | `py-1.5` (6px) | ❌ 不是 4 的倍数 |
| Hero top padding | `pt-28` (112px) | ⚠️ 112 是 4 的倍数，但值偏大 |
| 卡片 padding | `px-5` (20px) | ❌ 不是 4 的倍数 |

**修复方案**: 所有间隔必须为 4 的整数倍 → `py-2.5`→`py-2` 或 `py-3`，`py-1.5`→`py-1` 或 `py-2`，`px-5`→`px-4` 或 `px-6`。

### D5. 滚动条样式未按设计

| 属性 | 当前 | 设计 |
|------|------|------|
| 宽度 | 6px | — (未明确) |
| thumb 色 | `#1e2030` | 应使用 `neutral.600` `#2E2E3F` |
| thumb hover | `#2a2d3e` | 应使用 `neutral.500` `#4A4A5E` |

### D6. ::selection 颜色使用非品牌色

| 当前 | 设计 |
|------|------|
| `rgba(59,130,246,0.2)` (blue) | 应使用 `brand.400` `rgba(167,139,250,0.2)` |

### D7. 分隔线组件未统一

全站使用 `border-[#1e2030]` 硬编码，应统一为：
- 默认: `border-neutral-600`
- subtle: `border-white/4`
- gradient: CSS linear-gradient

## ❌ 缺失：暗黑/亮色模式系统

### 严重缺失项

| 设计要求 | 当前状态 |
|---------|---------|
| CSS 自定义属性 `--color-*` 体系 | 仅定义了 8 个自定义属性（非设计 token） |
| 完整 brand/neutral/semantic CSS 变量 | ❌ 无 |
| `prefers-color-scheme` 自动检测 | ❌ 无 |
| 手动 theme switcher 组件 | ❌ 无 |
| `localStorage` key `aiflowhub-theme` | ❌ 无 |
| Light mode neutral palette | ❌ 无 |
| Mode transition animation | ❌ 无 |
| `color-scheme` 动态切换 | ❌ 硬编码 `dark` |

**修复方案（核心优先级）**: 
1. 重构 `globals.css`：按 DESIGN §3 定义所有 `--brand-*`、`--neutral-*`、`--semantic-*` CSS 变量
2. 通过 `[data-theme="light"]` 选择器覆盖 light mode 值
3. 在 `layout.tsx` 注入 `<ThemeProvider>` 读取 localStorage + matchMedia
4. 添加 `<ThemeSwitcher>` 组件到 TopNav / Sidebar

### D8. 缺少 Glass Card 实现

DESIGN.md 定义了 `surface-glass` + `backdrop-blur-md` 的 glass-card，当前代码未使用。

### D9. 错误状态语义色

代码使用原生 Tailwind 语义色（`red-400`、`red-500/10`），应使用设计系统定义：

| 当前 | 设计 |
|------|------|
| `text-red-400` 退出按钮 | `text-error`（dark: `#EF4444`，但有 adjusted hue） |
| `bg-red-500/10` | 应使用 `rgba(239,68,68,0.12)` 或 `--error/12` |

### D10. 缺少 shadcn/ui 集成

- 无 `components.json`
- 无 shadcn/ui 组件
- 按钮/卡片/输入框等全部手写

## 总结

当前前端代码与 DESIGN.md 存在**结构性差距**：品牌名、配色系统、暗黑模式、动效系统四大核心维度全部偏离设计规范。代码处于早期阶段，使用了 Tailwind 原生 blue/slate 色系作为占位，这是合理的起步状态。

**最关键的三件事**（完成即可消除 80% 的差距）：

1. **CSS 变量 + 配色迁移**（P0）：把 DESIGN.md §3 的颜色表搬到 globals.css，全站替换 blue→brand purple
2. **品牌身份修正**（P0）："API Hub"→"aiflowhub"，⚡→BrandLogo，"Unified AI API Platform"→"Chinese AI Models. One Global API."
3. **暗黑/亮色模式系统**（P0）：CSS custom properties 双主题切换

这三项完成后，产品视觉将从"通用蓝色 API 平台"转变为"AiflowHub 品牌紫色亚洲 AI 网关"。
