```

        ├── 拆解任务 → 生成清晰的任务描述 + 验收标准

        ├── 审查产出 → 反馈迭代 → 最终验收

            │   ├── 人工确认（域名注册、公司注册等物料）

            │   └── 高人工判断需求的任务
            │
            └── 子代理 (OpenClaw sub-agent / Claude Code)
                ├── 代码实现（后端/前端/脚本）
                ├── 自动化测试
```
