# AI 模型 API 聚合平台 — 需求调研报告

> 版本：v1 / 最后更新：2026-05-30

---

## 一、项目背景与定位

### 1.1 项目概述

搭建小型 AI 模型 API 聚合/转售平台，面向亚美尼亚周边市场，提供国内模型厂商的低成本 API 中转服务。用户通过一套 OpenAI 兼容端点（`https://api.deerflow.ai/v1`）、一个 API Key，即可调用多家中国 AI 厂商的模型。

### 1.2 发起人约束

| 维度 | 参数 |
|------|------|
| 团队规模 | 单人（梦遥） |
| 所在地 | 亚美尼亚 |
| 预算 | $1,000–2,000（一次性投入） |
| 月度运维 | < $50 |
| MVP 上线 | 1 个月 |
| 商业模式验证 | 3 个月 |

### 1.3 核心价值主张

- **统一接入**：一套 SDK、一个 Key、一个 base\_url，解决国内模型分散接入的问题
- **低成本**：国内模型价格远低于欧美（$0.07–0.30/百万 tokens vs OpenAI $2.50–10.00/百万 tokens）
- **多模型覆盖**：DeepSeek、智谱、Moonshot、通义千问等主流国产模型聚合
- **区域友好**：面向亚美尼亚、格鲁吉亚、伊朗、土耳其、俄罗斯、乌克兰开发者，这些地区月薪 $500–1,500，欧美模型定价超出可承受范围

## 三、可行性分析结论

### 3.1 技术可行性 ✅

- **核心网关**：OneAPI（MIT 开源，社区活跃，支持 OpenAI 兼容格式）—— 已有成熟轮子
- **厂商对接**：8 家国内模型厂商中 3 家（DeepSeek / 智谱 Z.ai / 小米 MiMo）海外友好，可直接注册充值
- **部署方案**：Hetzner CX22（€4.35/月）单机 Docker Compose，零 GPU 需求
- **支付链路**：Stripe（美元）+ USDT TRC-20 双轨，覆盖受限地区用户

### 3.2 市场可行性 🟡

- **有利因素**：
  - 国内模型性价比极高（DeepSeek $0.27/百万 tokens 输入，仅为 OpenAI 的 1/10）
  - 目标区域开发者收入有限，对价格敏感
  - Telegram 社群活跃，触达效率高

- **不利因素**：
  - 部分国内厂商（字节豆包、月暗 Kimi）海外用户无法直接注册，限制模型丰富度
  - 初创平台冷启动获客难，靠内容营销和社群推广需要时间
  - 变现周期长：前 3 个月很可能仅能覆盖成本

### 3.3 商业可行性 🟢

- **启动成本极低**：初期投入 $36–41，月度运维 $15–35/月
- **盈亏平衡点低**：50 个付费用户（月均消费 $5）即可覆盖运维成本
- **盈利模式清晰**：模型加价转售（加价率 10–30%），薄利多销

### 3.4 结论

**建议推进。** 技术路线清晰、启动成本极低、风险可控。瓶颈不在技术而在获客。

## 四、竞品对比

### 4.1 直接竞品

| 竞品 | 定位 | 模型覆盖 | 价格 | 目标市场 | 优劣势 |
|------|------|---------|------|---------|-------|
| OpenRouter | AI API 聚合巨头 | 200+ 模型（含国内） | 略高于原厂 | 全球开发者 | 模型最全；但有加价，原厂便宜 |
| OneAPI 自建 | 开源自托管网关 | 自定义 | 无溢价 | 技术用户 | 零成本；需要自己维护账号和服务器 |
| API Hub（各类） | 中国模型转售 | 10–50 模型 | 有加价 | 英文市场 | 部分支持 USDT；但质量参差不齐 |

### 4.2 间接竞品

| 竞品 | 竞争维度 | 对平台的影响 |
|------|---------|------------|
| 各厂商官方 API | 低价 | DeepSeek/Z.ai 官方针对海外开放，用户可直接使用 |
| 阿里云百炼（国际站） | 模型市场 | 聚合了 DeepSeek、GLM 等，但需阿里云账号 |
| ChatGPT Plus 订阅 | 替代方案 | $20/月，非 API 用户不走 |

### 4.3 竞争壁垒

| 壁垒 | 本平台优势 | 可维持性 |
|------|-----------|---------|
| 定价透明度 | 统一加价 10–30%，避免用户逐家询价 | 中（竞品可跟进） |
| 多账号冗余 | 自动故障转移、多 Key 轮询 | 高（运维经验积累） |
| 支付友好 | Stripe + USDT，覆盖受限地区 | 中（友商也在补） |
| 社区获客 | Telegram 社群运营，非广告投放 | 高（人效比低） |

**结论**：不追求技术壁垒，价值在于"全链条打包后让开发者更省心"。

## 五、核心差异化

### 5.1 与 OpenRouter 的差异

- **定价更低**：OpenRouter 在各厂商上加价 20–100%，本平台控制在 10–30%
- **支付灵活**：OpenRouter 不支持 USDT/加密货币，本平台支持
- **区域加速**：Hetzner 法兰克福节点，东欧/中东延迟低

### 5.2 与自建 OneAPI 的差异

- **托管服务**：用户不需自己租服务器、运维网关
- **多 Key 池优化**：自动 Key 轮转、余额监控、故障切换
- **支付+账户一站式**：注册即用，信用卡/USDT 充值

### 5.3 与国内厂商官方的差异

- **统一管理**：一个余额池管理多家模型，不需逐个厂商充值
- **路由优化**：自动选最低延迟/最低价格模型，故障自动切
- **国际支付**：不需中国手机号、银行卡

## 七、风险评估

### 7.1 风险矩阵

| 风险 | 概率 | 影响 | 等级 | 应对 |
|------|------|------|:---:|------|
| **厂商 API 不稳定/下线** | 中 | 高 | 🔴 | 多厂商冗余 + 自动故障切换 |
| **API Key 泄露** | 低 | 高 | 🟡 | Key 轮转 + IP 白名单 + 用量告警 |
| **Stripe 入驻被拒（亚美尼亚）** | 中 | 高 | 🔴 | USDT 单轨兜底 + 备用 Paddle/LemonSqueezy |
| **获客困难** | 中 | 中 | 🟡 | 聚焦 2–3 个高活跃 Telegram 社群，内容营销引流 |
| **厂商涨价** | 低 | 中 | 🟡 | 加价率浮动 + 路由自动切到低价模型 |
| **合规/数据跨境** | 中 | 高 | 🔴 | Hetzner 芬兰节点（GDPR）；不持久化对话内容 |
| **汇率波动** | 中 | 低 | 🟢 | USDT 对冲 + 2% 溢价缓冲 |
| **DDoS/恶意刷量** | 低 | 高 | 🟡 | 速率限制 + Cloudflare + 用户级令牌桶 |

### 7.3 核心假设

以下假设是方案成立的前提，需在 MVP 阶段验证：

1. **价格敏感假设**：目标用户愿意因为 30–50% 的价格差异从官方 API 切换到第三方中转
2. **支付覆盖假设**：USDT 足以覆盖伊朗/俄罗斯用户的支付需求
3. **获客效率假设**：通过 Telegram 社群 3 个月可获得 50+ 付费用户
4. **厂商稳定假设**：DeepSeek / Z.ai / MiMo 不会在 1 年内关闭海外通道
