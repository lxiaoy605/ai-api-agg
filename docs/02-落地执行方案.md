## 三、技术选型决策

### 3.1 架构总览

```
用户 (OpenAI SDK / curl)
       ↓ HTTPS
Nginx (SSL 终端 + 速率限制)
       ↓
OneAPI 网关 (渠道分发 / 认证 / 计量)
       ↓
国内模型厂商 (DeepSeek / 智谱Z.ai / 小米MiMo / ...)
```

**完整版（含蓝绿部署）：**

```
负载均衡：HAProxy + Keepalived (VIP漂移)
API 网关：OneAPI × 2 (Blue + Green, 共享 SQLite WAL)
管理 API：Go 后端 (Gin + Stripe + USDT 引擎)
前端：Next.js (Vercel 免费层)
支付：Stripe Checkout + USDT TRC-20
监控：Prometheus + Grafana (自托管)
日志：结构化 JSON → ClickHouse
数据库：SQLite WAL 模式（零运维，够用）
```

### 3.2 核心技术选型

| 模块 | 选型 | 版本 | 理由 |
|------|------|:---:|------|
| API 网关 | OneAPI | latest | MIT 开源，OpenAI 兼容，社区活跃 |
| 部署编排 | Docker Compose | v5.1.3 | 单机运维，简单可靠 |
| 数据库 | SQLite (WAL) | 零运维 | 单人场景够用，避免 PG 运维成本 |
| 后端框架 | Gin (Go) | v1.12.0 | 性能好，生态成熟 |
| 前端框架 | Next.js | 15.5.18 | React 生态，SSR，SEO 友好 |
| 前端 UI | Tailwind CSS 4 + shadcn/ui | — | 现代速度，Together AI 设计语言 |
| 支付(法币) | Stripe Checkout | — | 国际通用，文档完善 |
| 支付(代币) | USDT TRC-20 + TronGrid | — | 低手续费，覆盖受限地区 |
| 负载均衡 | HAProxy + Keepalived | — | 零中断蓝绿部署 + VIP 漂移 |
| 监控 | Prometheus + Grafana | — | 轻量自托管 |

### 6.2 Stripe 替补方案

如 Stripe 因亚美尼亚地区不支持而无法入驻，按以下优先级启用替代方案：

| 优先级 | 方案 | 优点 | 缺点 |
|:-----:|------|------|------|
| 🥇 | Paddle | 支持全球收款，亚美尼亚注册也可用 | 4.9%+$0.50 费率略高 |
| 🥈 | LemonSqueezy | Paddle 白标代理，支持更多支付方式 | 5% 费率 |
| 🥉 | 纯 USDT | 0% 支付手续费 | 用户门槛高，需要懂加密货币 |

**建议策略**：先准备 USDT 通道兜底，同时申请 Stripe（用亚美尼亚当地公司信息），如 Stripe 拒了直接切 Paddle。
