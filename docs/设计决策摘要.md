# 设计决策摘要

> 源自 aiflowhub.ai — DESIGN.md v1.0

---

## 1. 为什么选蓝紫主色调（#3B2FCE → #7B61FF）？

- **品牌定位「连接」**：蓝紫色介于冷静蓝（技术、信任）和创造力紫（创新、亚洲美学）之间，传达理性 + 探索感。渐变方向 135°（左上→右下）模拟光照自然流向，暗示信息从源到目标的流动。
- **差异化**：主要 API 竞品（Together AI → 亮橙红、Mistral → 极简黑白蓝）均未使用蓝紫作为主色。蓝紫在深底色上发光效果好，天然适合 dark-first 产品。
- **中性层协调性**：该色相的辉光（`rgba(59,47,206,0.25)`）与冷中性灰（`#0A0A10` 背景）无色彩冲突，在代码/技术语境中保持「科技感」但不刺眼。

## 2. Inter + JetBrains Mono 字体选择理由

- **Inter**：专为屏幕设计的人本主义无衬线体，字符宽度一致、字距紧凑，适配 4px 网格系统的 UI 间距；同时是中文字体回退（PingFang SC / Noto Sans SC）的最佳搭档，中英文混排时行高不崩。
- **JetBrains Mono**：代码语境首选——连字（ligatures）丰富（`=>` `!=` `->` 等），字符定制了区分度高的 `0/O`、`1/l/I`，契合产品大量展示 API 请求/响应/代码示例的场景。
- **策略**：展示/正文用同一族 Inter，减少字体加载量；Mono 仅用于 code block 和 inline code，职责分离清晰。

## 3. Dark-first 策略为什么适合这个产品？

- **目标用户群是开发者**：开发者 90%+ 时间在 dark-mode IDE（VS Code/JetBrains）中工作，API 文档面板/仪表盘用深色减少从编码到网页的视觉跳跃。
- **技术展示场景**：API 响应 JSON、terminal curl 示例、网络拓扑图——这些内容在深色背景上对比度和可读性更高。
- **品牌氛围**：「中国模型出海 + API 聚合」需要稳定、高端的印象，深色模式比白色更易传达这种气质。
- **渐进增强**：Light mode 作为备选依然完整实现（`--color-*` CSS 变量切换），不牺牲可访问性。

## 4. 组件设计哲学（圆角/阴影/间距）

- **圆角 = 可感知的精致感**：卡片 12px、按钮 8px、输入框 8px、badge 全圆（9999px）。规则：可交互元素圆角小于容器（按钮 8px vs 卡片 12px），视觉层次分明。
- **阴影 = 海拔**：三层阴影（sm/md/lg）对应「表面」「升起」「悬浮」（卡片→下拉→弹窗）。附加 `shadow-glow` 用于品牌高亮，仅用在 feature card 等少数场景，不过度使用。
- **间距 = 4px 网格**：所有间距（`space-1`~`space-24`）为 4 的整数倍，跨组件边界对齐。16px 为默认间距，24px 为区域间距，64+px 为区块分割——间距本身是节奏。
- **整体哲学**：「技术产品不需要花哨，需要精准」。每个 token 都有唯一语义，不允许 ad-hoc 重写。

## 5. 参考 vs 独立创新

| 参考来源 | 借鉴了什么 | 独立创新 / 差异化 |
|----------|-----------|-------------------|
| **Together AI** | 品牌色作为数据可视化主色（chart-1 = brand） | Together 用亮橙，AiflowHub 用蓝紫 + 扩展的渐变色板；AiflowHub 的卡片层级更丰富（default/hover/glass三层） |
| **MiniMax** | 深色模式下高饱和强调色 + 半透明玻璃质感 | MiniMax 的玻璃效果更「碎」，AiflowHub 统一为 `surface-glass` token，且限制只在 feature card 使用 |
| **Mistral** | 极简色板、字重视角、大间距留白 | Mistral 几乎只有黑/白/蓝，AiflowHub 有完整的 10 级中性色和语义色，适应更多 UI 状态（表格/表单/标签） |
| **Linear** | 动效时长分类、easing 曲线命名、stagger 动画模式 | Linear 偏暖灰，AiflowHub 偏蓝紫冷灰；Linear 有大量视差滚动效果，AiflowHub 只在 hero 区域使用 |
| **独立创新** | — | ① 中文回退字体栈的明确策略（Inter + PingFang SC 混合排版）② 完整的 API 业务相关组件规格（code block 的 macOS 风格头栏 + 文件名 label）③ 品牌辉光 shadow-glow 作为一级 token 而非临时变量 |

## 6. 设计审查清单（产品子代理开发时检查）

### 色彩 & 主题
- [ ] 所有颜色只使用 `brand-*` / `neutral-*` / `semantic-*` CSS 变量，无硬编码 hex
- [ ] Dark/Light mode 都渲染正确，`<body>` 切换类名后所有 `--color-*` 正常切换
- [ ] 品牌主色 `#3B2FCE` 不单独用于小标签/辅助元素（用 `brand.300`/`brand.400` 代替）
- [ ] 辉光 shadow-glow 仅用在 feature/highlight 卡片，**不要**复制到普通卡片

### 排版
- [ ] 标题使用 `Inter` + 中文回退 `PingFang SC`，code 使用 `JetBrains Mono`
- [ ] 字号不从定义 scale（xs/2xl/5xl 等）之外的 size 直接写 `px`
- [ ] 正文 `text-base`（16px/24px），hero 最小 `text-3xl`（32px）
- [ ] heading 字号 ≥20px 时应用 `letter-spacing: -0.02em`

### 间距 & 布局
- [ ] 所有 `padding`/`margin`/`gap` 是 4px 整数倍
- [ ] 布局 container 遵循 breakpoint max-width：1024→1024px / 1280→1200px / 1536→1320px
- [ ] 侧栏在 `<768px` 为全屏 overlay，768–1023 为 icon-only collapsed，≥1024 展开

### 组件
- [ ] 按钮 variant/state 全部覆盖（primary/secondary/outline/ghost/destructive + hover/disabled/loading）
- [ ] 卡片 hover 时有 `shadow-glow` 或 border 变亮；玻璃卡片有 `backdrop-blur-md`
- [ ] 输入框 focus 时必须有 2px `brand.500` border + glow
- [ ] 表格 header 大写 + `tracking-[0.05em]`，row 有 hover bg
- [ ] Badge 用 pill（`rounded-full`），语义变体用对应主题色半透明 bg + 纯色 text

### 动效
- [ ] 仅用定义的 duration token（100/150/200/300/500ms），不使用 arbitrary ms
- [ ] Stagger list 子元素 delay `index × 50ms`
- [ ] `prefers-reduced-motion` 媒体查询到位
- [ ] Skeleton/spinner 使用 brand 色，不随意换色

### 代码 & API 展示
- [ ] Code block 背景 `#0D0D1A`（比 page 更深），border 1px `neutral.700`
- [ ] Code block header 高度 36px，含 macOS 风格按钮 + 可选文件名
- [ ] 行内代码 `font-mono` 大小为 0.875em，不单独定义

### 可访问性
- [ ] Focus ring 统一 2px `brand.500` + offset 2px
- [ ] 禁用状态 `opacity: 0.4` + `pointer-events: none`
- [ ] 灰色文本（`neutral.400`）不用于正文，仅用于 placeholder/hint
- [ ] 数据可视化色板与语义色不冲突（如 chart-5 紫色错误不与 error 红混淆）
